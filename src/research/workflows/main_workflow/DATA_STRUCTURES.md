# Main Workflow Data Types & JSON Structures

This document outlines all Pydantic models, internal data types, and their JSON structures used in [`main_workflow.py`](file:///d:/personal%20project/reserch2/research/workflows/main_workflow/main_workflow.py).

The workflow lifecycle consists of 3 primary phases:

1. **Planning Phase (Structured Output)**: The Task Orchestrator breaks the user task into parallel sub-agents and sequential layers.
2. **Instantiation Phase (Executable Schemas)**: Converts planned configurations into runnable LangGraph ReAct agents with bound tools and LLMs.
3. **Execution Phase (Result Schemas)**: Captures execution output per sub-agent, compiles layer summaries, and synthesizes the final response.

## 1. Planning Phase Schemas

These models represent the structured output generated by the **Task Orchestrator Agent** (`main_orchestrator`) when dividing a user query.

### 1.1 `SubAgentConfig`

Represents a single sub-agent configuration planned by the orchestrator.

#### Fields:

| Field           | Type  | Required | Description                                                     |
| --------------- | ----- | -------- | --------------------------------------------------------------- |
| `name`          | `str` | Yes      | Identifier / name of the sub-agent.                             |
| `system_prompt` | `str` | Yes      | System prompt defining the role, persona, and instructions.     |
| `task`          | `str` | Yes      | Specific sub-task assigned to this agent.                       |
| `model_name`    | `str` | Yes      | The LLM model to use (strictly `'deepseek/deepseek-v4-flash'`). |

#### JSON Structure:

```json
{
  "name": "Weather_Researcher",
  "system_prompt": "You are a weather specialist. Search current temperatures, weather conditions, and atmospheric details using available tools.",
  "task": "Retrieve current weather, temperature, and forecast for Tokyo, Japan.",
  "model_name": "deepseek/deepseek-v4-flash"
}
```

---

### 1.2 `BasicLayer`

Represents a sequential execution layer containing sub-agents that run in parallel.

#### Fields:

| Field          | Type                   | Required | Description                                                |
| -------------- | ---------------------- | -------- | ---------------------------------------------------------- |
| `layer_number` | `int`                  | Yes      | Sequential execution order number (e.g. 1, 2, 3...).       |
| `sub_agents`   | `List[SubAgentConfig]` | Yes      | List of sub-agents running concurrently within this layer. |

#### JSON Structure:

```json
{
  "layer_number": 1,
  "sub_agents": [
    {
      "name": "Weather_Researcher",
      "system_prompt": "You are a weather specialist. Search current temperatures, weather conditions, and atmospheric details using available tools.",
      "task": "Retrieve current weather, temperature, and forecast for Tokyo, Japan.",
      "model_name": "deepseek/deepseek-v4-flash"
    },
    {
      "name": "Events_Researcher",
      "system_prompt": "You are a local events scout. Find major public events happening in Tokyo today.",
      "task": "Discover outdoor festivals and cultural events happening in Tokyo today.",
      "model_name": "deepseek/deepseek-v4-flash"
    }
  ]
}
```

---

### 1.3 `TaskDivisionResult`

The top-level structured output of the planning LLM. Contains all layers ordered sequentially.

#### Fields:

| Field    | Type               | Required | Description                       |
| -------- | ------------------ | -------- | --------------------------------- |
| `layers` | `List[BasicLayer]` | Yes      | Ordered list of execution layers. |

#### JSON Structure:

```json
{
  "layers": [
    {
      "layer_number": 1,
      "sub_agents": [
        {
          "name": "Weather_Researcher",
          "system_prompt": "You are a weather specialist. Find current weather conditions in Tokyo.",
          "task": "Retrieve the current weather and precipitation forecast for Tokyo.",
          "model_name": "deepseek/deepseek-v4-flash"
        },
        {
          "name": "Events_Researcher",
          "system_prompt": "You are a cultural activities coordinator in Tokyo.",
          "task": "Find top outdoor and indoor sightseeing spots in Tokyo.",
          "model_name": "deepseek/deepseek-v4-flash"
        }
      ]
    },
    {
      "layer_number": 2,
      "sub_agents": [
        {
          "name": "Itinerary_Synthesizer",
          "system_prompt": "You are an expert travel planner. Combine weather data and attractions into a personalized day plan.",
          "task": "Using the weather and events findings from Layer 1, synthesize a comprehensive 1-day Tokyo itinerary.",
          "model_name": "deepseek/deepseek-v4-flash"
        }
      ]
    }
  ]
}
```

## 2. Instantiation Phase Schemas

These models represent initialized executable objects. They hold live references to initialized LLMs, tools, and compiled LangGraph ReAct agent executors.

### 2.1 `ExecutableSubAgent`

Wraps sub-agent configuration with active execution components.

#### Fields:

| Field           | Type                  | Required             | Description                              |
| --------------- | --------------------- | -------------------- | ---------------------------------------- |
| `name`          | `str`                 | Yes                  | Name of the sub-agent.                   |
| `system_prompt` | `str`                 | Yes                  | Formatted system prompt.                 |
| `task`          | `str`                 | Yes                  | Assigned task.                           |
| `model_name`    | `str`                 | Yes                  | LLM model name.                          |
| `llm`           | `Optional[Any]`       | No (default: `None`) | Live `ChatOpenRouter` instance.          |
| `tools`         | `Optional[List[Any]]` | No (default: `[]`)   | List of bound LangChain tools.           |
| `executor`      | `Optional[Any]`       | No (default: `None`) | Compiled LangGraph ReAct agent executor. |

#### JSON / Serialized Structure:

```json
{
  "name": "Weather_Researcher",
  "system_prompt": "You are a weather specialist...",
  "task": "Retrieve current weather for Tokyo.",
  "model_name": "deepseek/deepseek-v4-flash",
  "llm": "<ChatOpenRouter model='deepseek/deepseek-v4-flash'>",
  "tools": ["get_current_weather", "get_recent_models"],
  "executor": "<CompiledStateGraph (React Agent)>"
}
```

---

### 2.2 `ExecutableLayer`

Container for executable sub-agents in a given layer.

#### Fields:

| Field          | Type                       | Required           | Description                          |
| -------------- | -------------------------- | ------------------ | ------------------------------------ |
| `layer_number` | `int`                      | Yes                | Sequential layer index.              |
| `sub_agents`   | `List[ExecutableSubAgent]` | No (default: `[]`) | Executable sub-agents in this layer. |

#### JSON / Serialized Structure:

```json
{
  "layer_number": 1,
  "sub_agents": [
    {
      "name": "Weather_Researcher",
      "system_prompt": "You are a weather specialist...",
      "task": "Retrieve current weather for Tokyo.",
      "model_name": "deepseek/deepseek-v4-flash",
      "tools": ["get_current_weather"],
      "executor": "<CompiledStateGraph>"
    }
  ]
}
```

## 3. Execution Phase Schemas

These models capture the outcomes of runtime execution across all sub-agents and layers.

### 3.1 `SubAgentExecutionResult`

Detailed execution outcome of an individual sub-agent.

#### Fields:

| Field      | Type            | Required             | Description                                             |
| ---------- | --------------- | -------------------- | ------------------------------------------------------- |
| `name`     | `str`           | Yes                  | Name of the executed sub-agent.                         |
| `task`     | `str`           | Yes                  | Task assigned to the sub-agent.                         |
| `status`   | `str`           | Yes                  | Status: `"success"` or `"error"`.                       |
| `response` | `str`           | No (default: `""`)   | Final textual response content from the sub-agent.      |
| `messages` | `List[Any]`     | No (default: `[]`)   | Full LangChain message history (human, AI, tool calls). |
| `error`    | `Optional[str]` | No (default: `None`) | Error message if execution encountered an exception.    |

#### JSON Structure:

```json
{
  "name": "Weather_Researcher",
  "task": "Retrieve the current weather and precipitation forecast for Tokyo.",
  "status": "success",
  "response": "The current weather in Tokyo is 18°C with clear skies and a 10% chance of precipitation.",
  "messages": [
    {
      "role": "user",
      "content": "Assigned Task: Retrieve the current weather and precipitation forecast for Tokyo."
    },
    {
      "role": "assistant",
      "tool_calls": [
        {
          "name": "get_current_weather",
          "args": {
            "latitude": 35.6762,
            "longitude": 139.6503,
            "current_weather": true
          }
        }
      ]
    },
    {
      "role": "tool",
      "content": "{\"temperature\": 18.2, \"weathercode\": 0, \"windspeed\": 12.5}"
    },
    {
      "role": "assistant",
      "content": "The current weather in Tokyo is 18°C with clear skies and a 10% chance of precipitation."
    }
  ],
  "error": null
}
```

---

### 3.2 `LayerExecutionResult`

Aggregated results for all parallel sub-agents within a specific layer.

#### Fields:

| Field               | Type                            | Required           | Description                                                |
| ------------------- | ------------------------------- | ------------------ | ---------------------------------------------------------- |
| `layer_number`      | `int`                           | Yes                | Index of the executed layer.                               |
| `sub_agent_results` | `List[SubAgentExecutionResult]` | No (default: `[]`) | Results of each parallel sub-agent in this layer.          |
| `layer_summary`     | `str`                           | Yes                | Formatted text summary of all agent outputs in this layer. |

#### JSON Structure:

```json
{
  "layer_number": 1,
  "sub_agent_results": [
    {
      "name": "Weather_Researcher",
      "task": "Retrieve Tokyo weather.",
      "status": "success",
      "response": "Tokyo is currently 18°C and sunny.",
      "error": null
    },
    {
      "name": "Events_Researcher",
      "task": "Find top attractions in Tokyo.",
      "status": "success",
      "response": "Recommended attractions: Senso-ji Temple and Shinjuku Gyoen National Garden.",
      "error": null
    }
  ],
  "layer_summary": "[Layer 1 Outputs]\nAgent: Weather_Researcher\nTask: Retrieve Tokyo weather.\nOutput: Tokyo is currently 18°C and sunny.\n\nAgent: Events_Researcher\nTask: Find top attractions in Tokyo.\nOutput: Recommended attractions: Senso-ji Temple and Shinjuku Gyoen National Garden."
}
```

---

### 3.3 `ExecutionSummary`

Complete record of the entire multi-layer execution pipeline.

#### Fields:

| Field                   | Type                         | Required           | Description                                             |
| ----------------------- | ---------------------------- | ------------------ | ------------------------------------------------------- |
| `execution_history`     | `List[LayerExecutionResult]` | No (default: `[]`) | Ordered list of layer execution results.                |
| `accumulated_context`   | `str`                        | No (default: `""`) | Concatenated context passed sequentially across layers. |
| `final_response`        | `str`                        | No (default: `""`) | Synthesized final response from the last layer.         |
| `total_layers_executed` | `int`                        | No (default: `0`)  | Total number of executed layers.                        |

#### JSON Structure:

```json
{
  "execution_history": [
    {
      "layer_number": 1,
      "sub_agent_results": [
        {
          "name": "Weather_Researcher",
          "task": "Retrieve Tokyo weather.",
          "status": "success",
          "response": "Tokyo is currently 18°C and sunny.",
          "error": null
        }
      ],
      "layer_summary": "[Layer 1 Outputs]\nAgent: Weather_Researcher\nOutput: Tokyo is currently 18°C and sunny."
    },
    {
      "layer_number": 2,
      "sub_agent_results": [
        {
          "name": "Itinerary_Synthesizer",
          "task": "Synthesize a 1-day itinerary.",
          "status": "success",
          "response": "Since Tokyo is clear and 18°C today, start your morning at Senso-ji Temple, followed by an afternoon stroll in Shinjuku Gyoen.",
          "error": null
        }
      ],
      "layer_summary": "[Layer 2 Outputs]\nAgent: Itinerary_Synthesizer\nOutput: Since Tokyo is clear and 18°C today, start your morning at Senso-ji Temple, followed by an afternoon stroll in Shinjuku Gyoen."
    }
  ],
  "accumulated_context": "[Layer 1 Outputs]\nAgent: Weather_Researcher\nOutput: Tokyo is currently 18°C and sunny.\n\n[Layer 2 Outputs]\nAgent: Itinerary_Synthesizer\nOutput: Since Tokyo is clear and 18°C today, start your morning at Senso-ji Temple, followed by an afternoon stroll in Shinjuku Gyoen.",
  "final_response": "Since Tokyo is clear and 18°C today, start your morning at Senso-ji Temple, followed by an afternoon stroll in Shinjuku Gyoen.",
  "total_layers_executed": 2
}
```

## 4. Top-Level Workflow Response Structure

When `MainWorkFlow.main_orchestrator(task)` executes, it returns a combined dictionary:

```json
{
  "task_division": {
    "layers": [
      {
        "layer_number": 1,
        "sub_agents": [
          {
            "name": "Weather_Researcher",
            "system_prompt": "You are a weather specialist...",
            "task": "Retrieve current weather for Tokyo.",
            "model_name": "deepseek/deepseek-v4-flash"
          }
        ]
      }
    ]
  },
  "execution_result": {
    "execution_history": [
      {
        "layer_number": 1,
        "sub_agent_results": [
          {
            "name": "Weather_Researcher",
            "task": "Retrieve current weather for Tokyo.",
            "status": "success",
            "response": "18°C and sunny.",
            "messages": [],
            "error": null
          }
        ],
        "layer_summary": "[Layer 1 Outputs]\nAgent: Weather_Researcher\nOutput: 18°C and sunny."
      }
    ],
    "accumulated_context": "[Layer 1 Outputs]\nAgent: Weather_Researcher\nOutput: 18°C and sunny.",
    "final_response": "18°C and sunny.",
    "total_layers_executed": 1
  }
}
```
